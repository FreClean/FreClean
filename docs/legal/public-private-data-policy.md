# Public and Private Data Policy

## Public information may include

- FreClean name
- Brand
- Founder name where intentionally public
- General business activities
- General operating location
- Public website
- Public contact information
- General legal/compliance status

## Private information

- NIF
- NINU
- Identity documents
- Passport information
- Bank account information
- Tax documents
- Private contracts
- Insurance documents
- Supplier confidential information
- Private addresses
- Payment credentials
- API keys
- Passwords
- Database credentials
- JWT secrets
- Wallet private keys
- Seed phrases

Private information must never be committed to Git or published in this
repository. Public status records must not include confidential identifiers or
evidence contents.
